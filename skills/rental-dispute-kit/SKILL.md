# rental-dispute-kit：租房纠纷应对工具箱

> 目标：纠纷发生时不慌、不闹、不吃亏——按"定级→固证→分级行动→时间线"四步走。
> 核心纪律：**先固证再行动；升级路径只升不跳（除非对方跑路/诈骗，直接报警）。**
>
> ⚠️ 非律师意见声明：本 skill 为通用流程与文书模板，不是法律意见；起诉前建议咨询执业律师。

## 1. 何时使用

- 房东/中介扣押金不退或乱扣 → 第 4 节押金专项
- 家电坏了/漏水/甲醛，对方不修 → 第 5 节维修专项
- 要提前解约，对方索要天价违约金 → 第 6 节解约专项
- 二房东/中介失联跑路 → 第 7 节跑路专项（先报警）

**输入**：纠纷类型 + 一句话事实 + 手头已有的证据。
**输出**：《纠纷行动方案》（定级结论 + 证据缺口 + L1-L4 模板 + 时间线）。

## 2. 第一步：定级（先分类，再选路径）

| 级别 | 特征 | 首选动作 |
|---|---|---|
| L1 协商 | 对方还愿意沟通，只是"想多扣点/想拖一拖" | 微信文字协商，给台阶+给时限 |
| L2 函告 | L1 无回应/被拒，或对方开始耍赖 | 书面函告，列事实+依据+最后时限 |
| L3 投诉 | L2 无效，或对方资质有问题 | 12345 / 住建租赁科 / 市场监管 |
| L4 起诉 | 金额大（押金 5000+）、L3 无效、对方恶意 | 小额诉讼 / 人民调解 |

**直接 L4 的两种情况**：① 对方卷款跑路疑似诈骗 → 先报警；② 对方威胁、换锁、断水电 → 报警 + 同步走 L2 函告。

## 3. 第二步：证据链自查（五件套，缺什么补什么）

- [ ] ① 合同原件（含补充条款、交接清单附件）
- [ ] ② 租金/押金转账记录（备注写清"X 月租金/X 押金"；现金→找收条+证人）
- [ ] ③ 入住时的房屋状态证据（交接清单签字版、照片、视频）
- [ ] ④ 全程沟通记录（微信文字版；语音→转文字后请对方文字确认）
- [ ] ⑤ 现状证据（损坏照片、维修报价单、对方拒绝维修的聊天记录）

**补救办法**：转账记录去银行/支付平台拉流水（对方否认收款时最硬）；聊天记录做公证/法院认可的存证（金额大时值得花这几百块）。

## 4. 押金专项：三档话术（复制即用，填 [] 即可）

### L1 友好协商（微信文字）

```
[X 哥/X 姐]你好，我是 [小区+房号] 的租客 [你的名字]。
咱们合同 [X] 月 [X] 日到期，我已按约定结清费用、打扫完毕，
验收时 [已验收合格/你方未提出异议]。
按合同第 [X] 条，押金 [金额] 元应于 [X] 日内退还。
麻烦你确认下退还时间，我把收款账号发你：[账号]。
```

### L2 正式函告（微信/邮件文字，语气转正式）

```
关于退还租房押金的函告
[对方姓名]：
本人 [姓名]，身份证号 [XXX]，于 [日期] 与你签订《房屋租赁合同》，
承租 [地址]，押金 [金额] 元。
本人已于 [日期] 结清全部费用并交还房屋，[验收合格/你方未在约定
时限内提出异议]。现要求你于 [X] 年 [X] 月 [X] 日前将押金原路退还。
逾期本人将向 12345 及住建部门投诉，并通过诉讼途径主张权利，
届时产生的诉讼费等将一并主张。
特此函告。
[你的名字] [日期]
```

### L3/L4 路径

- **12345**：话术"实名投诉 [地址] 房东 [姓名] 无故扣押租房押金 [金额] 元，合同约定 [X] 日内退还，逾期未退，请求协调。"材料：合同+转账+验收证据。
- **小额诉讼**：诉讼请求写三项——① 退还押金 X 元 ② 逾期利息（按 LPR，自逾期日起）③ 诉讼费由被告承担。事实理由按时间线写，证据按"五件套"编号附目录。

## 5. 维修专项

1. **书面报修**（微信文字）："[X 哥]，[具体位置]的[设备]坏了，[故障现象]，按合同第 [X] 条属 [自然损耗/结构问题]，麻烦 [X] 天内安排维修。"——留时间戳，这是后两步的前置条件。
2. **对方拖延**：第二次催告 + "如 [X] 日内未维修，我将自行维修，费用 [预计 X 元] 从租金中抵扣，并保留凭证。"
3. **自行维修抵扣**：找正规维修开票，费用从下期租金扣除，书面告知对方。注意：只适用于"自然损耗/结构问题"，人为损坏别用这招。
4. **甲醛/漏水等居住安全问题**：先做检测（CMA 机构报告最硬），超标→要求退租+退押金+赔偿搬家损失；对方不认→12345/住建投诉。

## 6. 提前解约专项

1. 看合同：通知期几天？违约金上限多少？按合同走是成本最低的。
2. 合同没写/写得苛刻：谈减免话术——"我提前 [X] 天通知，帮你带看找下家，无缝衔接你没空置损失，违约金咱们按半个月走，你看行不？"（核心逻辑：用"帮对方减少损失"换"对方减少你的损失"。）
3. 找下家转租：经房东书面同意转租，押金和剩余租金转给下家，三方签个简单的转让确认。
4. 搬离前：书面确认交房时间、抄水电表数、拍照、全程录像——别给"东西丢了/弄坏了"留口子。

## 7. 二房东/中介跑路专项

1. **先报警**：带合同、转账记录、对方身份信息去派出所。是否立案看金额和性质，但**报案回执**是后续一切维权的前置。
2. **找原房东**：说明情况，争取按原租金直接跟原房东签（你手里的转租合同+付款记录是谈判筹码）。
3. **住建+市场监管投诉**：中介无资质经营、资金池操作是重点打击项。
4. **别做的事**：别信"新公司接盘，交 X 钱激活"；别把原件给任何"好心人"。

## 8. 时间线管理（给用户的行动表）

```
D0 今天：固证（第 3 节五件套）+ 发出 L1
D3 无回应/被拒：发出 L2，设 D7 为最后时限
D7 仍无解决：L3 投诉（12345/住建），同步准备 L4 材料
D14 投诉无果/金额大：L4 起诉或人民调解
```

每一步升级前确认：上一级的"已送达"证据在手（微信已读、邮件回执、EMS 签收）。

## 9. 起诉状要点清单（小额诉讼可直接套用的结构）

> 提醒：以下为文书结构模板，不是代写诉状；递交前建议请执业律师过一遍。

```
民事起诉状
原告：[姓名]，[性别]，[出生日期]，身份证号 [XXX]，住 [地址]，电话 [XXX]
被告：[姓名/公司名]，身份证号/统一信用代码 [XXX]，住 [地址]，电话 [XXX]

诉讼请求：
1. 判令被告退还原告租房押金人民币 [X] 元；
2. 判令被告支付逾期退还押金的利息（以 [X] 元为基数，
   自 [逾期之日] 起按全国银行间同业拆借中心公布的贷款市场报价利率
   计算至实际清偿之日止）；
3. 本案诉讼费用由被告承担。

事实与理由：
[按时间线写：何时签约、租了哪里的房、押金多少、何时到期、
何时交房验收、对方如何拒绝退还/乱扣、你做过哪些催告]
[每一段事实后面建议标注证据编号，如"（证据 3：微信聊天记录）"]

证据目录：
证据 1：《房屋租赁合同》——证明租赁关系与押金约定
证据 2：押金/租金转账记录——证明已支付
证据 3：房屋交接/验收记录——证明已交还且合格
证据 4：催告记录（微信/函告）——证明对方逾期未退
证据 5：[其他，如维修报价单、检测报告]

此致
[XX 区]人民法院
具状人：[签名]  [日期]
```

**立案实务 5 问**（先打法院诉讼服务热线 12368 问清）：
1. 管辖法院：一般是被告住所地或合同履行地（房屋所在地）法院。
2. 小额诉讼：标的额低于当地上年度就业人员年平均工资 50% 的多适用，一审终审、审理快。
3. 诉讼费：1 万元以下 50 元，简易程序减半。
4. 立案材料：起诉状（按被告人数+1 份）、原被告身份材料、证据复印件。
5. 开庭：带齐证据原件；对方不到庭，法院可缺席判决——不到庭不吃亏的是你。

## 10. 调解 vs 诉讼：怎么选

| 维度 | 人民调解 | 小额诉讼 |
|---|---|---|
| 费用 | 免费 | 诉讼费 50 元起 |
| 时间 | 几天到几周 | 1-3 个月 |
| 强制力 | 调解书可申请司法确认→有强制执行力 | 判决书直接可执行 |
| 适合 | 对方愿意谈、金额不大、想快 | 对方耍赖、金额大、要个"说法" |
| 注意 | 调解不成不影响起诉；调解中别轻易让步超 20% | 起诉后法院也会先调解，调解不成再判 |

**决策树**：对方失联/耍赖 → 直接诉讼；对方愿意谈但差价在 20% 内 → 调解；拿不准 → 先调解，调解员会告诉你"这案子起诉稳赢/悬"，等于免费咨询。

## 11. 反模式（这些做法是错的）

1. **电话里吵一架** → 吵完没证据。所有关键沟通走文字。
2. **私自换锁/赶人/断水电**（房东视角）→ 违法，可能从有理变没理。
3. **威胁"不退钱就曝光你"** → 涉嫌敲诈勒索的边界，别碰。用合法投诉渠道施压。
4. **证据散落在多个手机/聊天软件** → 第一时间归档到一个文件夹+云端备份。
5. **L1 没走完直接起诉** → 法官先问"协商过吗"，程序走完胜算和调解率都更高。

## 12. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. 定级结论是否明确（L1/L2/L3/L4 之一）？→ 不许"先试试再说"。
2. 证据五件套是否逐项确认，缺口是否有补救动作？
3. 给用户的时间线是否具体到日期？→ "尽快"不算时间线。

标准冒烟用例：见仓库根 `smoke_test.py`。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-rental/issues，正文写清"输入 → 错误输出 → 期望输出"。
