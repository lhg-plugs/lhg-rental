# /lhg-rental:dispute —— 租房纠纷应对

用户输入在 `$ARGUMENTS` 中：`[纠纷类型] [一句话描述]`。类型不明先问一句，别猜。

> ⚠️ **非律师意见声明**：以下为通用应对流程与文书模板，不是法律意见；起诉前建议咨询执业律师。

## 流程（加载 skill `rental-dispute-kit`）

### 1. 定性（先分类，再行动）

| 纠纷类型 | 关键词 | 首选路径 |
|---|---|---|
| 押金不退/乱扣 | 退租、验收、扣款 | 协商→函告→12345→小额诉讼 |
| 维修扯皮 | 漏水、家电坏、甲醛 | 书面报修→自行维修抵扣→投诉 |
| 提前解约 | 换工作、违约金 | 按合同通知期→谈减免→留证据搬离 |
| 二房东/中介跑路 | 失联、转租 | 报警（涉诈骗）+ 起诉 + 住建投诉 |

### 2. 证据链自查（输出缺什么补什么）

必备五件套：① 合同原件 ② 租金/押金转账记录（备注用途）③ 交接清单与入住照片 ④ 沟通记录（文字版）⑤ 验收/损坏现状证据。
缺哪件给哪件的补救办法（如只有现金无转账→找收条/证人）。

### 3. 分级行动模板

- **L1 协商话术**：微信文字模板，语气留余地、事实摆清楚、诉求给时限（"请在 X 月 X 日前…"）。
- **L2 正式函告**：书面函模板，列明事实、合同依据、法律依据（《民法典》相关原则，不编具体条文号）、最后时限。
- **L3 投诉**：12345 / 住建租赁科 / 市场监管（涉中介）的话术与材料清单。
- **L4 起诉**：起诉状要点清单（当事人信息、诉讼请求、事实理由、证据目录）、小额诉讼流程说明、诉讼费参考。

### 4. 时间线管理

给用户一张行动时间表：今天做什么、3 天后没回复做什么、7 天后升级到哪。每一步都要有"对方已读/已回复"的留痕要求。

## 硬规则

- 不许教用户伪造证据、威胁恐吓、私自换锁赶人。
- 不许编造"某地法院判例"；要举例就写"类案通常…"并提醒以当地司法口径为准。
- 对方疑似诈骗（卷款跑路）→ 第一优先级是报警固定证据，不是先协商。
