# /lhg-rental:rental —— 租房全流程避坑

用户输入在 `$ARGUMENTS` 中：`[合同文本文件路径] [--city 城市]`。没给文件就先问用户粘贴合同文本（存为临时文件再扫）。

> ⚠️ **非律师意见声明**：本命令输出为通用风险提示与流程建议，不是法律意见；各地租赁条例差异大，以当地最新规定为准，真涉诉请咨询执业律师。

## 流程（加载 skill 顺序）

### 1. 合同风险扫描（必做，先跑脚本）

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/contract_audit.py --target <合同所在目录> --format text
```

- blocker（霸王条款/关键信息缺失）：逐条解释"为什么危险"+"怎么改"，给出改写后的条款原文。
- warning（金额异常/信息缺失）：给出谈判话术（见 skill `rental-dispute-kit` 第 3 节）。
- 脚本扫不到的（中介资质、二房东授权链、房源真伪）：转第 2 步人工清单。

### 2. 房源与中介核验（加载 `rental-trap-list`）

按 skill 第 2 节"签约前 10 查"逐项过：

- 出租方身份 → 要求身份证/营业执照原件拍照
- 房屋权属 → 房产证或转租授权链
- 中介资质 → 营业执照 + 备案（警惕无门店纯线上中介）
- 房源真伪 → 实地看房、核对门牌与房产证地址

每项输出"✅ 已确认 / ⚠️ 待补充 / ❌ 有风险"。

### 3. 押金专项（加载 `rental-deposit` 对应能力）

- 押金 ≤ 1 个月租金？超了怎么谈（话术模板）。
- 押金扣除标准是否写死清单？退还时限是否写死天数？
- 输出《押金保护三件套》：交接清单签字 + 入住全屋拍照/视频 + 租金押金转账备注写清用途。

### 4. 输出《租房避坑报告》

按以下结构输出（中文、可打印）：

1. 风险总览：blocker X / warning Y，一句话结论（签 / 谈完再签 / 别签）
2. 条款级修改建议表（原文 → 风险 → 改写建议）
3. 签约前待办清单（带勾选框）
4. 纠纷预案：押金不退/提前解约/房屋问题三类话术入口（指到 `/lhg-rental:dispute`）

## 硬规则

- 不许说"这份合同没问题"——只能说"脚本未发现风险信号"，并提醒人工复核。
- 不许编造当地条例的具体条文号；要引用就写"以当地住建部门最新规定为准"。
- 用户没给城市时，不许假设城市出政策结论。
