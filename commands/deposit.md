# /lhg-rental:deposit —— 押金退还专项

用户输入在 `$ARGUMENTS` 中：`[押金金额] [月租金] [--city 城市]`。

> ⚠️ **非律师意见声明**：以下为通用流程建议，不是法律意见；各地规定不同，以当地最新规定为准。

## 流程（加载 skill `rental-dispute-kit` 第 4 节）

### 1. 先算一笔账

- 押金 / 月租金 = X 倍。X > 1 → 当初多交了，退租谈判时这是你的筹码（"押金本就超额，扣除更要讲证据"）。
- 列出合同里写死的"可扣项"（没有？那对方扣任何钱都要拿出依据）。

### 2. 退租前 7 天自查（输出可打印清单）

- [ ] 对照入住时的《交接清单》逐项检查，损坏先自己修（小钱）比被扣（大钱）划算
- [ ] 全屋保洁做到"交接清单照片级"（重点：油烟机、马桶、地板）
- [ ] 水电燃气结清，缴费凭证截图存档
- [ ] 提前书面（微信文字，别语音）通知退租，留时间戳

### 3. 验收当天

- 要求对方**当场**逐项验收并在清单上签字；拒绝"你先走，回头算"。
- 验收过程录像（告知对方正在录像）。
- 钥匙交接写收条，注明"房屋已交还，验收合格/不合格项如下"。

### 4. 扣款争议话术（加载 skill 取模板）

三档话术：① 友好协商（给台阶）→ ② 正式函告（列法条+时限）→ ③ 投诉/起诉（12345、住建、法院）。
每档给可直接复制的文字模板，把 [房东名]/[金额]/[日期] 填上就能用。

### 5. 还是不退？升级路径

1. 12345 市民热线 / 当地住建部门租赁管理科投诉
2. 人民调解委员会（免费）
3. 法院小额诉讼（标的 5 万以下流程简化，诉讼费 50 元起）
4. 全程证据链自查：合同、转账记录、交接清单、验收录像、聊天记录——缺哪个补哪个

## 硬规则

- 不许承诺"一定能要回"；只能给概率与路径。
- 涉及金额、日期的模板必须留占位符让用户填，不许编数字。
